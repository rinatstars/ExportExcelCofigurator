# ExportExcelConfigurator

Графическая утилита настройки системы автоматического экспорта
результатов анализа из **Atom** в **Excel**.

Программа предназначена для удобной настройки параметров работы утилиты
**exportExcel** без ручного редактирования конфигурационных файлов.

------------------------------------------------------------------------

# Назначение

`ExportExcelConfigurator` позволяет пользователю:

-   настраивать параметры экспорта Excel
-   выбирать элементы анализа
-   задавать структуру выходных таблиц
-   изменять пути хранения файлов
-   управлять параметрами обработки XML отчётов

Все настройки сохраняются в файл:

    settings.json

который используется программой **exportExcel**.

------------------------------------------------------------------------

# Основные возможности

## Настройка элементов анализа

Позволяет:

-   выбрать элементы, которые будут экспортироваться в Excel
-   задать порядок элементов
-   исключить ненужные элементы

Это позволяет адаптировать Excel‑отчёты под конкретную методику анализа.

------------------------------------------------------------------------

## Настройка путей файлов

Можно задать:

-   папку, где Atom сохраняет XML отчёты
-   папку, куда будут сохраняться Excel файлы

Основной параметр:

    xml_folder

Обычно используется:

    Atom\Reports

------------------------------------------------------------------------

## Редактирование структуры Excel

Configurator позволяет:

-   изменить порядок колонок
-   настроить формат данных
-   задать дополнительные поля

Это позволяет адаптировать таблицу под требования лаборатории или
производственного отчёта.

------------------------------------------------------------------------

# Архитектура системы

    Atom
    │
    ├─ Reports
    │  ├─ XML отчёты
    │  │
    │  └─ scripts
    │      ├─ exportExcel.exe
    │      ├─ ExportExcelConfigurator.exe
    │      ├─ settings.json
    │      ├─ version.txt
    │      └─ _internal

Configurator изменяет файл:

    settings.json

который используется программой **exportExcel**.

------------------------------------------------------------------------

# Файл конфигурации

Основной файл настроек:

    settings.json

Пример:

``` json
{
    "xml_folder": "C:\\Atom 3.3 x64\\Reports",
    "excel_folder": "C:\\Atom 3.3 x64\\Reports",
    "elements": [
        "Si",
        "Fe",
        "Al"
    ]
}
```

## Параметры

### xml_folder

Папка, где Atom сохраняет XML отчёты.

### excel_folder

Папка для сохранения Excel файлов.

### elements

Список элементов, которые будут включены в Excel таблицу.

------------------------------------------------------------------------

# Использование

## Запуск программы

Запустите:

    ExportExcelConfigurator.exe

Откроется графическое окно настройки.

------------------------------------------------------------------------

## Изменение настроек

1.  Выберите элементы анализа
2.  Проверьте путь к XML отчётам
3.  Настройте параметры Excel
4.  Сохраните настройки

После сохранения будет обновлён файл:

    settings.json

------------------------------------------------------------------------

# Взаимодействие с exportExcel

После настройки:

1.  Atom завершает анализ
2.  Создаёт XML отчёт
3.  Запускает **exportExcel**
4.  exportExcel читает **settings.json**
5.  Формирует Excel таблицу

------------------------------------------------------------------------
